# ReinSymPDE

Code for the paper **"ReinSymPDE: Efficient Free-Form PDE Discovery Method Combining Reinforcement Learning and Transformer-based Model"**.

> **Status:** The code is being prepared and verified. It will be released in this repository by the end of October 2026.

## Overview

ReinSymPDE discovers free-form partial differential equations (PDEs) from data by combining:

- a frequency-aware denoising network that gives accurate derivatives from noisy observations through automatic differentiation,
- reinforcement-learning selection of derivative terms, and
- a pre-trained transformer-based symbolic regression model (E2E) with diversity-boosted decoding and expression simplification.

## Planned contents

- Source code for the full pipeline
- Scripts to reproduce the MDBench clean and noisy experiments, the transcendental-PDE experiments, and the practical simulation benchmark
